# open-folder

デスクトップに常駐する小型ランチャーウィジェット。登録したプロジェクトフォルダをワンクリックで VS Code / Cursor / Antigravity で開けます。WSL 内パスにも対応。

## 使い方

- **マウスオーバー / 左クリック**: 登録パス一覧のパネルを表示 → 行をクリックでエディタ起動
- **行を右クリック**: そのパスを編集
- **アイコンを右クリック**: 設定メニュー(パス追加・管理 / エディタ切替 / 常に手前に表示 / 終了)
- **左ドラッグ**: ウィジェットを移動(位置は保存される)
- **Ctrl+Alt+Z**: マウスがどこにあってもパネルを表示/非表示(ホットキーで開いた場合、一度パネルにマウスを乗せるまで自動では閉じません)

エディタは設定メニューの「エディタ」から VS Code / Cursor / Antigravity を切り替えられます。

## パスの種類

パスを追加するとき、入力した文字列から種類を自動判定します。

- **Windows パス**(`C:\project` など) → `code "C:\project"` で開く
- **WSL パス**(`/home/user/project` など。`/` 始まりは自動で WSL 判定) → Windows 側のエディタに WSL リモートとして渡して開く
- **UNC 形式**(`\\wsl.localhost\Ubuntu\home\...` または `\\wsl$\...`) → 入力すると自動で WSL パスに変換されます

## スタートアップに登録(自動起動)

`startup.bat` を実行すると、`publish\OpenFolder\OpenFolder.exe` へのショートカットをスタートアップフォルダに自動作成します。

```
.\startup.bat
```

次回ログオンから自動起動します。再実行しても同じショートカットを上書きするだけなので安全です。

手動で行う場合は次の手順です。

1. `publish\OpenFolder\OpenFolder.exe` のショートカットを作成する
2. `Win + R` → `shell:startup` でスタートアップフォルダを開く
3. 作成したショートカットをそこに置く

> `publish` フォルダが無い場合は、先にビルドが必要です(下記)。

## ソースから実行・ビルド

```
dotnet run
```

開発時のビルド・テスト・再起動の手順は [AGENTS.md](AGENTS.md) を参照してください。

## 設定ファイル

`%APPDATA%\open-folder\settings.json` に保存されます(登録パス・エディタ・最前面設定・ウィンドウ位置)。
読み込めない場合は `settings.json.bak` に退避してから初期化します。
